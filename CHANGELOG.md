# Changelog

All notable changes to this project are documented in this file.

## 0.1.6

- Rename the command and settings namespace from `codexUsage` to `codexUsageBiz`.

## 0.1.5

- Rename the extension to Codex Usage (Business).

## 0.1.4

- Use direct GitHub image URLs so screenshots render reliably in locally installed VSIX packages.

## 0.1.3

- Add Marketplace icon, banner, search keywords, and project resource links.
- Add status-bar and hover-detail screenshots to the extension documentation.
- Add changelog and support guidance.

## 0.1.2

- Show Codex usage, rate-limit status, and spend-limit reset time in the status bar.
- Add detailed hover information and manual refresh support.
- Add automatic refresh and configurable account, locale, and request timeout settings.

## 0.1.1

- Format dates using the VS Code display language or a configured locale.

## 0.1.0

- Initial release.
